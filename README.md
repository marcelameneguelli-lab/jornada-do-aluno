# Jornada do Aluno · Secretaria Acadêmica VR

CRM unificado da Secretaria Acadêmica da Estácio Volta Redonda: Renovação, Engajamento, Provas, Estágio, Financeiro, Financiamentos, NPS e Formandos, com login único e perfis de acesso.

- Aplicativo: `index.html`, `nucleo/`, `modulos/` (publicado pelo GitHub Pages)
- Servidor: `gas/` (Google Apps Script, colar no projeto "Jornada do Aluno · Central")
- Documentação: `docs/ARQUITETURA.md` e `docs/CHECKLIST_RECURSOS.md`

Os dados de alunos e os acessos ficam só nas planilhas do Google. Este repositório não guarda senhas nem bases.

Desenvolvido por Marcela Meneguelli.
